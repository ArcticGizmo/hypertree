Concept · spatial mode

The map becomes a place, not a ladder

Today the map is a stack of rows: main in the middle, branches hung above and below, each a horizontal timeline where position is structure. Spatial mode drops that. Desktops become rooms you place anywhere on a grid and they stay put — real spatial memory. Structure moves into groups: a named, coloured set of rooms that is purely logical, together or scattered.

How the old model maps across

branch (a row)→group — a stable colour over any rooms
main (the pivot row)→main — the bucket for any ungrouped room
dive / surface axis→gone; you jump straight to a room
left/right in a row→free 2-D placement, snapped to a grid

main is just the default bucket

Nothing about main is special anymore — it's simply where a desktop lives when it has no group. Make a room, ungroup one, and it drops into main automatically. Its hull is drawn faint and neutral because it isn't a deliberate grouping, just "everything else."

Grouping & colours — g / ⇧G

g steps through the groups; the whole set lights and moves as one. ⇧G opens the group list, where each group carries a stable colour you pick from the palette — so the memory you build ("the coral group is billing") survives adding, removing and reordering.

A keyboard hierarchy for moving things

Four scopes, smallest to largest: arrows move the cursor; Ctrl+arrows move the selected room a cell; Ctrl+⇧+arrows move the whole contiguous block the room sits in; and dragging with ⇧ (or after g) moves the entire group, scattered pieces and all.

Deleting keeps your map still

In rows, delete shifts every neighbour left; spatially that would wreck the memory you just built — so Del removes a room and leaves the hole, with a dashed ghost lingering for a moment. ⇧Del removes a whole group the same way. Nothing else jumps.

Tidy up — t — respects logical shape

Tidy is the broom for drift and gaps. When a group has split into fragments it magnets them back together — but moves each fragment as a rigid block, so the little arrangements you built stay intact rather than being re-squared. Then it packs the groups so none overlap, animated and reversible. Select a group to tidy just it; with nothing selected it tidies the whole map.

Use whichever you prefer — Tab

Spatial doesn't replace the row view — Tab flips between them and animates the same rooms into place, so the classic List (today's Board / Metro / ASCII) and the new Spatial map are two lenses on one arrangement. Pick per taste, per moment.
