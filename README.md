# Hypertree

Give git worktrees a **scope** — a named set of Windows virtual desktops you can
*dive into* and *surface out of* — so switching worktrees stops meaning "hunt
through a wall of lookalike windows."

Your day-to-day desktops stay on the usual horizontal axis. Each worktree becomes
a scope that hangs *below* an anchor desktop. `Win+↓` dives in, you work as normal,
`Win+↑` surfaces back out — landing exactly where you left off.

## Status

Design locked (**Model P — dive / surface**); technical feasibility not yet proven.
Next step is the M0 feasibility spike.
